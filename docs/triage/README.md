# Triage Notes

This directory stores generated or hand-curated maintainer snapshots used during revival work.

Generate a current open pull request report with:

```bash
python scripts/pr_backlog_report.py --repo trimstray/the-book-of-secret-knowledge > docs/triage/open-pr-backlog.md
```

Do not treat a snapshot as live truth after it ages. Regenerate before a release.
